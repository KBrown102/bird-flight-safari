# 飞鸟漫游 · Bird Flight Safari

俯视角 2D 飞鸟小游戏：一只小鸟从星空一路向上飞，循环穿越五个场景 —— 星空 → 海洋 → 沙漠 → 草原 → 冰原，再回到星空。

## 在线试玩

https://KBrown102.github.io/bird-flight-safari/

## 操作

| 按键 | 效果 |
|------|------|
| ← / A | 向左滑翔（机身左倾） |
| → / D | 向右滑翔（机身右倾） |
| ↑ / W | 振翅加速上升 |
| ↓ / S | 振翅减速下降 |
| 只按左右 | 滑翔状态（不振翅），机身朝转向方向扭过去 |

## 本地运行

**方式一**：直接双击 `index.html` 用浏览器打开即可。

**方式二**：启动本地静态服务器

```bash
node serve.js
```

然后浏览器打开终端里显示的本地地址（默认 http://localhost:8124）。

## 技术说明

- **Three.js**：背景分层着色器，绘制星空 / 海洋 / 沙漠 / 草原 / 冰原五个场景及其贝塞尔曲线边界过渡。
- **Canvas 2D**：叠加绘制飞鸟、同伴鸟、海洋光点、星空星芒、冰原雪花、飞鸟影子与尾迹。
- 纯前端单文件，无需构建步骤，Three.js 通过 CDN 引入。

## 文件

- `index.html` —— 游戏本体
- `serve.js` —— 本地静态服务器
- `start.bat` —— 一键启动（Windows）
